# Group implementation

M0 chỉ tạo ranh giới module. Không có implementation FFTformer, FSAS, DFFN, loader, CLI hay demo tại đây. Bất kỳ API mới nào phải khớp `docs/contracts.md`, có owner và test tương ứng.

- `model/`: WS1
- `data/`: WS2
- `inference/`, `app/`: WS3
- `evaluation/`: WS4
- `common/`: only shared utilities approved through an interface discussion
